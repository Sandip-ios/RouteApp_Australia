      What works in v5

      Fully working (needs internet)

      • Several routes on this phone: create, open, rename, copy, delete
      • Each stop is a Delivery or a Pickup, with a parcel count you can change
      • After Delivered / Failed / Skip the next stop slides in, with the following two shown
      • Up to 200 stops; import a run sheet (.csv) or pasted address list
      • Several parcels at one address grouped into one stop, with run-sheet numbers
      • Australian address search; pins marked "Check pin" when only the street was found
      • Move any pin by tapping the map
      • Route optimisation of every pending stop together, using road travel times
      • Use my location as the start, with a live blue dot while the page is open
      • Drag-and-drop or ▲▼ reordering
      • Pending, delivered, failed (with reason) and skipped statuses
      • Auto-save and resume on this device, named copies, export/import file

      Demonstration only

      • Free public map services: no guaranteed uptime, no live traffic
      • If road times are unavailable, the plan uses straight-line estimates (marked "Estimate")
      • In-app voice navigation works while the app is open and the screen is on; no live traffic. Google Maps is still available for each stop
      • Location tracking only while this page is open and the screen is on

      Not built yet

      • Navigation with the screen off or in the background, and live traffic
      • Reading a paper run sheet from a photo
      • Delivery time windows, multiple drivers, proof of delivery
      • Accounts, cloud sync and business dashboard
