# Dropline Route Planner (prototype v2)

Mobile-first multi-stop delivery route planner for Australian drivers.
Single-file web app (`index.html`) using free, open services:
OpenStreetMap map tiles, Photon/Nominatim address search, OSRM public demo routing.

- Up to 200 stops; import a run sheet (.csv) or pasted address list
- Whole-route optimisation using road travel times
- Delivery statuses, live location, saving on the device

No customer data is stored in this repository: imported lists stay on the driver's phone.
Prototype only: no built-in turn-by-turn navigation yet.
